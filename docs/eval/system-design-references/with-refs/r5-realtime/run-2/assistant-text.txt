- **Tasks:** 4.
  1. Add a metrics helper and a contract file describing how the page should poll.
  2. Give the paid model call a 90 s limit and check it for errors.
  3. Skip a repeated job when its section already has text.
  4. Make the report endpoint return progress and a "finished" signal, let the page skip unchanged reports, and cap reads at 5 s.
- **Follow-up issues:** 2, both marked to be filed after merge.
  - The section-generation route has no access check, so anyone can call it and trigger paid model calls.
  - Sections that fail for good should show as failed instead of looking stuck.

  - **Needs your answer (Q1):** This repo has no page or frontend. The plan only covers the server side plus a written polling contract. Viewers will see no change until someone adds a 2-second polling loop to the page.

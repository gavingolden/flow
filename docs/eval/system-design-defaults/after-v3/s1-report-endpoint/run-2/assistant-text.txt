- **Problem:** The service can read and share reports but can't create one. Making five model calls one after another inside the request is risky. At 20–60 s per call, the request can run into Cloud Run's 300 s limit. A report kept in one server's memory is lost on restart and can't be seen from other instances. And the service is public with no limit on model spend.
- **Tasks:** 7 in total:
  1. A metrics helper.
  2. A timeout and status check on the model client.
  3. Durable storage in Firestore.
  4. A Cloud Tasks queue client.
  5. A background worker that saves each section as it finishes.
  6. The `POST /reports` endpoint, plus changes to reading and sharing reports.
  7. Deploy and Dockerfile changes.

  The plan passed the three plan-format checks (`flow-plan-lint`, `flow-candidate-issues --lint`, `flow-test-steps-lint`).
